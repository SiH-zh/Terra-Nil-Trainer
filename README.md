# Terra Nil（伊始之地）修改器

伊始之地游戏修改器。通过 BepInEx（模组加载框架）随游戏加载，在游戏内显示中文面板，提供资源、建造、动物和地图操作。

当前源码归档版本：**1.3.0**。本仓库按版本标签保留 10 个开发版本；第一次公开上传时统一整理，并未伪造早期提交日期。日常使用推荐 **[1.4.0 发布包](https://github.com/SiH-zh/Terra-Nil-Trainer/releases/tag/v1.4.0)**；旧版标为历史预发布版，已知问题见[历史版本](docs/历史版本.md)。

## 下载、安装与更新

1. 在[发布页](https://github.com/SiH-zh/Terra-Nil-Trainer/releases)下载 `Terra-Nil-Trainer-v1.4.0.zip`，不要把代码托管平台自动生成的源码压缩包当作安装包。
2. 完整解压，保持“伊始之地修改器.exe”与“载荷”目录在一起。
3. 保存进度并退出游戏，运行安装工具，选择实际游戏安装目录。
4. 点击“检查与预览”，通过后点击“安装／更新修改器”。
5. 正常启动游戏，按 F6 显示或隐藏中文面板。已有自定义快捷键会保留。

安装器备份旧插件和找到的存档，不替换游戏原程序集。卸载前退出游戏，再使用安装工具；有其他插件时保留共享加载框架。发布包附压缩包 SHA-256（文件校验算法）及内部校验清单。

主要适配 Windows（视窗系统）64 位、游戏平台构建 `22566272`、游戏 `1.2.12`、Unity（游戏引擎）`2022.3.62f2` 的 Mono（托管运行环境）版本。其他平台及游戏版本尚未全面验证。详细操作见[使用说明](docs/使用说明.md)，验证范围见[验证记录](docs/验证记录.md)。

## 使用边界

动物推荐按需求与扩张规则估算，不能保证迁移后的最终心情。活动范围增加领地容量，仍受适宜地形、地图大小与实际需求限制。

地形笔刷保留高度，水体和冰面效果受关卡规则影响；操作会通过原命令影响气候、进度和自动存档。无限撤销每步保存完整快照并占用内存，读档、阶段变化及不可撤销边界会清空历史。请保留存档备份。

隔离人工地图测试包括真实地块处理及原生鼠标射线，也使用场景、快照恢复与显示夹具。所有真实关卡、44 种地形的原生素材、长期生态和特殊撤销流程尚未全面验收。

## 从源码编译

需要本地合法安装的游戏、Windows PowerShell（系统脚本环境）5.1 及系统 .NET Framework（托管开发框架）C#（编程语言）编译器。本仓库不分发游戏依赖程序集。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\编译.ps1 -GamePath 'D:\Games\Terra Nil'
```

将示例路径替换为自己的游戏目录。脚本下载官方加载框架并核对固定校验值，也可通过 `-LoaderZip` 指定事先下载的官方压缩包。仅在仓库的 `.cache` 与 `dist` 中写入文件，不安装或修改游戏。构建输出是本地开发包；正式对外分发应补齐第三方对应源码和整包校验，见[第三方组件](docs/第三方组件.md)。

历史版公开包仍附原编译脚本；版本标签里的 `scripts/编译.ps1` 使用统一构建方式，原 C# 源码按当版保留。老版加载及交互问题不会因重新编译自动修复。
