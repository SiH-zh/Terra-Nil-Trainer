# 伊始之地中文修改器

这是一个随游戏启动的模组，附带中文安装与卸载工具。当前版本：**1.2.1 面板加载修复版**。适配你当前安装的游戏 **1.2.12，构建编号 22566272**。

本版修复：**日志显示加载成功，但按键与面板没有反应**。安装工具会备份并修正加载入口，让插件在合适的时机进入游戏循环。保留自定义快捷键、动物心情、迁移推荐、货币与建造功能。

面板隐藏后，左上角有“打开修改器”按钮，可用鼠标重新打开。插件日志会记录首次按键更新、首次面板绘制和快捷键触发，方便定位后续问题。

## 如何使用

1. 如果下载的是压缩包，先完整解压；保持“载荷”文件夹和“伊始之地修改器.exe”在同一个目录。
2. 退出游戏，双击“伊始之地修改器.exe”。默认游戏目录为 `<游戏安装目录>`。
3. 点击“检查与预览”。按钮先显示“正在检查”，结束后状态行显示绿色通过或红色失败，以及检查次数和北京时间。绿色通过后点击“安装／更新修改器”。第一次安装会备份本地存档；通过本工具安装的旧版可直接升级，不需要先卸载，升级会备份旧插件、安装记录和当前存档。注意：“检查与预览”只检查，不会安装。
4. 照常从 Steam（游戏平台）启动游戏，或点击安装工具的“启动游戏”。
5. 面板启动时显示，默认按 **F6** 隐藏或重新打开，原 F8 已不再是默认按键。“货币与建造”和“动物心情与迁移”页分别包含对应功能。
6. 隐藏面板后操作游戏。面板显示时拦截放置操作，避免点击面板导致误建造。

如果此前已安装旧版，仍需执行新版的“安装／更新修改器”，再重新启动游戏；只解压压缩包不会修复实际游戏目录。安装工具会保留已选择的快捷键，请检查控制键、上档键、交替键是否被勾选。使用组合键时需同时按下对应修饰键。

每次重新启动游戏，三个倍率恢复为 1，两个开关关闭。货币只有点击“设置数量”才修改，不会持续锁定。

## 自定义快捷键

### 在游戏面板里设置

1. 默认按 F6 打开面板。
2. 点击面板顶部的“自定义快捷键”。
3. 按下你希望使用的主按键；可同时按住 Ctrl（控制键）、Shift（上档键）或 Alt（交替键），组成组合键。
4. 录制成功后显示保存结果，新快捷键立即生效，下次启动仍会使用这个设置。

按 Esc（退出键）取消录制，原快捷键保留。点击“恢复默认 F6”可恢复为单独按 F6。支持 F1—F12、字母、数字、空格、方向键以及列表中的导航键；修饰键需要配合一个主按键。

组合必须完整匹配。例如保存为控制键、上档键加字母 K 时，少按一个修饰键或额外按住交替键，都不会切换面板。

### 快捷键被其他软件占用、打不开面板时

退出游戏，打开本版安装工具，在“面板快捷键”处选择主按键，按需要勾选修饰键，然后点击“保存快捷键”。下次启动游戏生效。这个入口需要本版插件已经安装；已有旧版时，先点击“安装／更新修改器”，会同时保存当前选择的快捷键。

配置保存在游戏目录的 `BepInEx/config/local.terranil.chinese.trainer.cfg`。安装工具改写前会备份原配置，保留其他设置。“关闭全部修改”不会重置你保存的快捷键。

正在运行的游戏已经加载旧插件，必须退出并重新启动才能切换到本版；只下载新包或在另一目录打开新安装工具，不会更新当前游戏进程。

## 动物心情与迁移

游戏中这个数值是兽群的心情，并非对玩家的好感度；每个兽群共享一组心情和领地需求。

### 心情拉满

- “当前所有兽群心情一键拉满”：将已有、仍有领地的兽群当前及目标心情设置为 100%，清除因心情不足安排的离开计时。
- “仅将选中兽群心情拉满”：只处理面板中选中的兽群。
- “持续保持所有兽群满心情”：开启后，原游戏重新计算心情时继续保持 100%，也会处理后来出现的兽群。退出游戏或“关闭全部修改”后恢复默认关闭。

一键设置后，如果没有开启持续保持，游戏会再次根据实际需求调整心情。需求栏目仍显示真实的空间、食物、水源等状态，不会全部伪造为“理想”。已经被遣散或失去全部领地的兽群不会被复活。

### 迁移位置推荐

1. 在动物页使用“上一群”“下一群”选择兽群；也可以先隐藏面板，在游戏中选中动物，再打开面板点击“采用游戏中选中兽群”。
2. 点击“扫描当前兽群的最佳迁移候选”。扫描会显示百分比，可取消。扫描过程中保持地图尽量稳定；大地图可能需要等待。
3. 结果显示当前领地原始评分，以及前三个候选的坐标、预计心情、需求状态和估算领地格数。
4. 点击“定位并标记候选”，镜头移到候选位置。按 F6 隐藏面板后，会看到绿色十字及坐标标记。
5. 使用游戏原有的兽群迁移操作，将动物移到对应格子。扫描和定位不会自行迁移动物，也不会扣除货币；实际迁移费用和解锁条件按游戏规则执行。

评分使用游戏原有的需求计算函数、领地扩张函数以及当前难度下的领地上限。开始时按迁移后的适中心情估算领地，再依据预测心情调整上限，最多迭代四轮；如果上下限循环，采用较低评分作为保守估计。

候选起点遵守原有的动物迁移限制，包括地形、高度、同类兽群占用、燃烧、放射性和声波影响。相同评分优先选择未满足需求较少、距离当前领地较近的位置。三个候选可能属于同一片适宜区域。

**推荐功能始终使用原始评分；即使持续满心情已开启，也不会把所有地点评成 100%。**气候等需求可能无法通过换位置改善，结果会据实显示。如果没有比当前领地更好的候选，界面会明确提示。

**这是当前地图下、按领地扩张估算得到的最佳候选，不是迁移后必定达到的最终心情或未来全局最优解。**实际逐步扩张、其他动物移动、建筑与气候变化会改变结果。扫描期间检测到地形、兽群领地或气候变化，会提示重新计算；遇到某些起点评分失败，也会明确提示搜索不完整。点击定位时会再次核对起点是否合法。

“关闭全部修改并清除推荐”会停止持续满心情、恢复原有建造与范围开关，并清除扫描结果和地图标记；已设置的心情不会立即退回旧值，而是随后由游戏按环境重新计算。

## 原有六项功能

| 功能 | 效果与边界 |
|---|---|
| 设置叶子货币 | 将当前关卡货币设为输入的整数，范围 0—9999999。必须先进入关卡。 |
| 灌溉器覆盖范围 | 支持 1—5 倍，围绕建筑中心放大灌溉器原有旋转形状，填充扩大后的区域，保留原覆盖范围，并裁剪地图外坐标。改变的是覆盖区域，不是只改显示。 |
| 回收器回收范围 | 支持 1—5 倍。处理回收信标、回收筒仓、空中回收相关建筑、装载港和陆地回收车的回收半径。保留原有可回收对象规则；不改变回收车行驶范围、护盾或水路寻路。 |
| 其他建筑作用范围 | 对采用通用作用半径的建筑支持 1—5 倍，并处理太阳能阵列的专用半径。特殊建筑自定义的线路长度、连接数量或专属算法不全部属于该半径；地图核污染源不扩大。 |
| 任意位置建造 | 放宽地形类型与高度要求；地图内仍需有完整占地。不会强制覆盖已有建筑、燃烧或放射性地块、回收车所在格。 |
| 忽略建造条件 | 放宽放置时的供电等资源检查、根部及跨占地条件、限制区域检查，并让建筑气候适宜度按理想状态计算。不会解锁全部建筑、跳过游戏阶段、免除货币成本，也不会创建特殊建筑所需的关联对象。 |

三个范围倍率相互独立，不叠乘。**1 倍表示原始范围**。提高线性范围会增加更多受影响格子，5 倍时计算量可能明显增加。

范围改变主要作用于下一次建造、预览或回收操作。已经完成的地形变化和已缓存的供电关系不会自动重新计算；需要时重新建造对应建筑。

“任意位置”与“忽略条件”可以一起打开。特殊建筑仍可能依赖前置建筑、运输连接、动画流程等；本版不承诺每一种特殊建筑在所有位置都能正常工作。若出现异常，关闭开关，先在普通建筑和新关卡上验证。

## 安装内容与恢复

安装工具添加以下内容，不替换原游戏代码文件：

- `winhttp.dll`、`doorstop_config.ini` 和 `.doorstop_version`：模组加载入口。
- `BepInEx/core/`：BepInEx（模组加载框架）5.4.23.5 所需文件。
- `BepInEx/plugins/TerraNilTrainer/TerraNilTrainer.dll`：本修改器插件。
- `.TerraNilTrainer/`：安装记录、文件校验清单和存档备份。
- `BepInEx/config/BepInEx.cfg`：只修正加载入口节中的三个字段，其余设置和注释保留；原始字节副本保存在 `.TerraNilTrainer/加载配置备份-*`。卸载保留该配置与备份。需要恢复旧配置时，先退出游戏，再复制备份的“原加载配置.cfg”覆盖此文件。

备份来源为当前用户的 `AppData\LocalLow\Free Lives\Terra Nil`，包括其中的用户配置、关卡存档、备份存档和截图，跳过运行日志。存档备份目录名使用北京时间。

卸载时先退出游戏，再打开安装工具点击“卸载修改器”。工具逐项核对自己安装的文件，将文件移到 `.TerraNilTrainer/卸载恢复-*`，保留存档、备份、运行日志及配置。检测到其他插件时，保留共享加载框架，仅移走本插件。文件被其他程序改写时，停止自动卸载，避免移动不再属于本安装版本的文件。

**卸载和“关闭全部修改”不会回退已经设置的货币或已经保存的地形变化。**需要回退时，退出游戏，保留现有存档副本，再从存档备份目录恢复相应文件；游戏平台云存档可能需要另行确认同步版本。

## 已有模组框架时

自动安装会停止，避免覆盖现有加载框架。若你已有兼容的 BepInEx（模组加载框架）5.x，可手动把“载荷”中的 `BepInEx/plugins/TerraNilTrainer` 整个文件夹复制到游戏目录下的同名插件目录。手动安装不会自动备份存档，也不会创建自动卸载记录；卸载时退出游戏，移走这个插件目录即可。

## 版本更新与排错

游戏代码文件校验值不同，插件和安装工具都会拒绝修改。游戏更新后需重新适配，不能凭版本名称相似强行使用。

面板没有出现时，检查游戏目录的 `BepInEx/LogOutput.log`，是否有“伊始之地中文修改器 1.2.1”和“版本匹配，建造及动物功能就绪”。没有这些记录时，插件尚未成功加载，不应认为已生效。

“加载成功”不等于已经进入游戏循环。正常启动还应有“面板按键更新已运行”和“面板已绘制”两条记录。若缺少它们，退出游戏，再运行本版“安装／更新修改器”，修复加载入口后重新启动。修复方式对应[加载框架官方排错说明](https://docs.bepinex.dev/articles/user_guide/troubleshooting.html#change-the-entry-point)。
