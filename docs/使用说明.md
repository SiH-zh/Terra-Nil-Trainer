# 伊始之地中文修改器 1.3.2

适配游戏1.2.12、游戏平台构建22566272。随游戏加载，默认F6显示或隐藏面板，自定义快捷键保留。修改开关默认关闭，动物活动范围默认1倍；地图标记默认显示已计算的结果。

## 安装与更新

1. 完整解压压缩包，保持“载荷”目录与“伊始之地修改器.exe”在一起。
2. 先保存进度并退出游戏，再运行安装工具。默认目录为 `<游戏安装目录>`。
3. 点击“检查与预览”，通过后点击“安装／更新修改器”；检查本身不安装。已有本工具安装记录时直接升级，自动备份旧插件、安装记录和当前存档。
4. 正常从游戏平台启动。面板启动时显示，按F6隐藏或重新打开；快捷键也可在工具或游戏面板中自定义。面板隐藏后左上角有“打开修改器”。
5. 面板外可以正常预览和建造；仅面板内部及拖动过程中的点击被拦截。

安装工具会备份并修正加载框架入口，保留其他配置，避免“日志加载成功但面板没有反应”。正常启动日志应包含“面板按键更新已运行”及“面板已绘制”。

## 鼠标拖动调整面板大小

鼠标按住面板任一边框拖动，可以改变宽度或高度；按住四角拖动可同时改变宽高。边框靠近鼠标时会亮起，右下角有角标。拖动标题栏可移动面板，点击“恢复面板大小”回到初始位置和尺寸。

面板最小逻辑尺寸为440×320，放大受当前屏幕限制；小分辨率会随界面比例适配，屏幕变化时自动移回可见区域。内容始终可以滚动，缩小时不删除功能。窗口尺寸只在本次游戏运行期间保留。

缩放期间会捕获鼠标，避免把拖动误当成地图操作；松开鼠标或隐藏面板后释放捕获。面板外正常预览、建造的行为保留。

## 一键拉满并持续保持心情

此前的全体“一键拉满”只设置一次，游戏随后会按当前栖息地重新计算，所以心情可能回落。1.3.1改为“所有兽群一键拉满并持续保持”：点击后自动开启下方“持续保持所有兽群满心情”，设置当前兽群的当前及目标心情为100%，并持续覆盖新出现的兽群。

面板明确显示保持是否开启。隐藏菜单不会关闭保持；取消全体勾选可停止全体保持；单独保持的种群仍生效。“关闭全部修改”可停止全部保持。每次启动游戏默认关闭，需要重新点击开启。关闭保持后心情会恢复按原游戏的栖息地规则更新。

需要始终满心情时，可使用全体持续按钮或下方按种群名字单独保持的按钮。保持不改变实际栖息地需求。

本功能不伪造动物实际需求、不改变动物生成条件、不复活已被遣散的兽群。迁移推荐继续按原始环境评分，不会因保持开启而全部变成满分。开启、关闭和设置结果会记录到加载框架日志，便于诊断。

## 指定动物种群拉满心情（好感）

在“动物心情与迁移”页，按动物种类和游戏里的种群名字选择，例如鹿的“清溪家族”。可搜索名字，或在原游戏选中动物后点击“采用游戏中选中种群”。

在选中种群的详情中点击“只将「名字」拉满并持续保持”。这个按钮只开启该具体种群的保持，不开启全体保持，也不同时修改同种的其他家族。可依次选中多群分别开启；名单会标注“单独保持”，上方显示当前名单与数量。隐藏菜单后仍生效。

取消“单独保持「名字」满心情”即可关闭该群。如果“全体持续保持”仍开启，该群仍会被全体功能保持；只想保持指定动物时，先关闭全体保持。关闭全体保持不会删除已经明确设置的单群保持；“关闭全部修改”会取消两种保持。

“仅选中兽群心情拉满一次”保留为单次设置；没有开启任何保持时可能按环境回落。

单群保持绑定实际种群对象，不按名字猜测替代对象。兽群被遣散、离开或合并后清除其保持；重启、读档、换关卡以及撤销替换关卡状态时清空单群名单，需要重新按名字选择。不会把保持误套到另一个同名种群。全体开关继续按本次会话设置运行，新启动默认关闭。

## 按种群名字推荐居住地

进入“动物心情与迁移”页，在种群名单中按动物种类及游戏中的名字选择。例如同为鹿的“清溪家族”和“苔原家族”会分别显示，推荐绑定实际种群对象，不使用会随顺序变化的编号。可以输入名字或动物种类筛选，也可先在游戏里选中具体动物，再点击“采用游戏中选中种群”。本版不会自动替你选择第一群动物。

选中后先显示动物种类、种群名字、只数、当前心情、领地中心及当前领地格数和上限，再扫描该种群的候选位置。每个结果显示同一名字、推荐迁移起点坐标、高度、预计心情、估算领地格数和各项需求状态。

评分使用游戏的真实需求公式；持续满心情不影响推荐评分。模拟按动物的安全地块、连通地形、高度变化、同类占用及声波规则扩张，严格限制领地容量；不会把邻近危险地块或超过容量的格子算进去。新活动范围会纳入评分。

**动物实际扩张还有需求优先级与随机择地，这里是当前地图的扩张估算，不保证迁移后的最终心情。**如果最佳预测不比当前领地更好，会明确提示。扫描过程中或之后地图、领地、气候、建筑、声波、难度或范围设置改变，旧预测会标橙并提示重算；旧预测不再用于定位。

## 全部最佳点地图标记

扫描结束后默认显示该具名种群全部预测最高分的同分点，不限于前三个位置。

- 绿色小点：全部预测最高分的迁移起点。
- 带名字与数字的十字：最多5个分散代表候选，避免都挤在同一小片区域。
- 橙色标记：地图等条件已变化，属于旧预测，需要重新扫描。

**菜单展开时也显示标记。**标签尽量避开菜单并减少重叠。面板有显示标记开关和清除按钮。“定位并标记候选”把镜头移到对应点；实际迁移仍用游戏原有操作，不会自动移动动物或免除迁移费用。当前只标记按名字选中的具体种群；切换种群会清除之前的推荐，防止认错。

## 增加动物活动范围

动物页提供1—5倍选项，作用于当前及新出现的种群。原游戏使用不规则领地与格数容量，没有统一圆形活动半径；这里按近似线性范围倍率扩大容量：2倍约4倍格数、3倍约9倍格数，最多受地图面积限制。

动物随后通过游戏原有扩张流程逐步取得更多活动地块。保留地形、高度、危险区、同类占用和原有需求规则，不让陆生动物直接占据海洋等不合适地形，不改变共用动物生成数据。适宜地块不足时不会一定达到新上限；已经满足需求的动物也可能不继续扩张。

1倍恢复原容量；已经取得的活动地块不会立即删除。范围设置不随重启保留，已保存的领地变化不会自动回退。改变倍率会清除旧推荐，请重新扫描。

## 无限撤销上一步

在“货币与建造”页开启“无限撤销上一步”，随后游戏允许撤销的玩家操作会累积历史，**不设固定步数上限**。可反复点击本面板“撤销上一步”，也可继续使用游戏原有撤销按钮；每次退回一步，显示剩余记录数。

- 默认关闭。开启前已丢失的历史不能恢复；若游戏当前确有一步可撤销记录，可纳入该一步。
- 仅在本次关卡会话记录。重启、读档、切换关卡、进入原游戏不可撤销流程或阶段边界时清空，避免混用不同关卡或无效流程的快照。
- 游戏本来不支持撤销的特殊操作不会强制变成可撤销。货币设置、心情设置、活动范围切换等修改器按钮不单独作为撤销步骤。
- 使用原游戏的完整关卡快照和恢复流程，因此撤销恢复的是该步骤前的关卡状态，可能同时退回后续自然演变或动物状态，而非只删掉一栋建筑。
- 每步快照占用内存；关闭开关释放额外历史，保留游戏原有的最新一步记录。

“关闭全部修改”会关闭无限撤销并清空额外历史，同时关闭持续满心情、恢复动物和建筑范围倍率、清除推荐。已经设置并保存的货币、地形和动物领地不会凭此按钮回退。

## 保留的功能

| 功能 | 作用 |
|---|---|
| 叶子货币 | 设置当前关卡货币0—9999999，一次设置，不持续锁定。 |
| 灌溉器范围 | 1—5倍，放大原有旋转形状，填充扩展区域并裁剪地图边界。 |
| 回收器范围 | 1—5倍，处理回收建筑及陆地回收车的回收半径，保留可回收对象和寻路规则。 |
| 其他建筑范围 | 1—5倍，处理通用作用半径与太阳能阵列专用半径；不扩大地图核污染源，不包办所有特殊线路长度和专属算法。 |
| 任意位置建造 | 放宽地形与高度，继续拦截越界、已有建筑、危险地块等。 |
| 忽略建造条件 | 放宽资源、供电、根部及跨占地条件、限制区域和建筑气候适宜度；不解锁全部建筑、不免除货币成本、不创建特殊关联对象。 |
| 动物满心情 | 全体或按种群名字单独拉满并保持；可只取消指定兽群，也保留单次设置。停止保持后按环境更新。 |
| 自定义快捷键 | 支持单键与控制键、上档键、交替键组合；完整匹配，自动保存。 |

建筑三个倍率独立，不叠乘。范围变化主要影响后续预览、建造、回收或动物扩张，不自动重算全部已有建筑的缓存关系。全部修改每次启动恢复关闭或1倍；快捷键单独保存。

## 备份与卸载

本工具不替换原游戏程序集。载荷包含官方模组加载框架和本插件；安装记录、旧插件、原加载配置及存档备份在游戏目录的 `.TerraNilTrainer` 内。退出游戏后用工具卸载，自有文件移入可恢复目录，保留配置、日志和存档；存在其他插件时保留共享框架。升级也不替换共享框架。

恢复存档前先退出游戏并保留当前存档副本。需要恢复加载配置时，退出后复制备份的“原加载配置.cfg”覆盖 `BepInEx/config/BepInEx.cfg`。源码及中文编译脚本在“源码”目录，编译只生成交付包；第三方许可证与来源说明在“第三方许可”目录。
