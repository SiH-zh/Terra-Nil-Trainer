# 伊始之地中文修改器 1.5.0

适配游戏1.2.12、游戏平台构建22566272。随游戏加载，默认F6显示或隐藏面板，自定义快捷键保留。**无限撤销每次启动默认开启；其他修改、高亮、地形涂抹和地块拾取器默认关闭，各种范围默认1倍。**

首次使用建议先读[图文使用教程](图文使用教程.md)，其中包含安装、快捷键、资源、动物、迁移、高亮、地形笔刷及撤销的分步操作与界面预览。本页用于查阅详细规则与限制。

## 安装与更新

1. 完整解压更新包，保持“载荷”目录与“伊始之地修改器.exe”在一起。
2. 保存进度并退出游戏，再运行安装工具。点击“选择目录”指定实际游戏安装目录，确认其中有游戏启动文件和数据目录。
3. 点击“检查与预览”，通过后点击“安装／更新修改器”。检查本身不安装；升级会自动备份旧插件、安装记录和找到的当前存档。
4. 正常从游戏平台启动。面板启动时显示；按F6显示或隐藏。隐藏后左上角有“打开修改器”。快捷键可在安装工具或游戏面板里自定义，支持单键和控制键、上档键、交替键组合。


## 窗口大小与地图操作

按住面板任一边框拖动可调整宽度或高度，四角可同时调整宽高；拖动标题栏移动面板。“恢复面板大小”恢复初始位置和尺寸。边框悬停时亮起，右下角有角标。

最小逻辑尺寸440×320，最大受屏幕限制；小屏幕自动缩放，分辨率变化时移回可见区域。内容仍可滚动，窗口大小只在本次运行保留。缩放时捕获鼠标，松开后恢复地图操作。未开启地形涂抹时，面板外正常预览和建造。

## 指定物种的活动范围

进入“动物心情与迁移”页，打开“按物种分别设置活动范围”。搜索并选择鹿、熊等物种，也可点击“采用选中兽群的物种”。选择1—5倍后点击“应用到此物种”。

物种设置作用于该物种当前及以后出现的所有家族。**物种单独倍率覆盖通用倍率，不叠乘。**例如通用2倍、鹿3倍，则鹿为3倍，未单独设置的其他物种为2倍；也可明确把某物种设为1倍。点击“此物种恢复继承通用”删除该物种的单独设置。下方显示当前单独设置名单。

游戏中的活动范围是不规则领地，修改扩大的是领地格数容量：2倍约4倍格数、3倍约9倍格数，受地图面积限制。动物按原扩张流程逐步获得地块，仍受适宜地形、高度、危险区、同类占用和实际需求限制；已满足需求或适宜地块不足时不一定继续扩张。不改变共用动物生成数据。

1倍恢复原容量，但已经占据的地块不会立即删除。范围在本次会话生效，重启恢复1倍；“关闭全部修改”同时清除通用和物种设置。范围变化会清除旧推荐，需要重新扫描。

## 上帝之手：气候调节

打开“上帝之手”页，顶部有温度、湿度、毒性、辐射四个滑块。拖动后在下一次游戏更新中立即设置为显示的目标值，不需要点击应用，也不需要开启地形涂抹。支持保留动物需求详情查看环境变化。

| 项目 | 范围与单位 |
|---|---|
| 温度 | −10～50℃，整数步进。 |
| 湿度 | 0～100%。 |
| 毒性 | 0～100%。 |
| 辐射 | 0～500 CPM（每分钟计数）。 |

范围由原游戏资源读取。**不同关卡启用的参数不同**：例如焦黑火山口只有温度与湿度；极地关卡通常支持毒性；部分城市及干旱关卡支持辐射。未进入关卡显示“请先进入关卡”，本关没有的项目显示“本关未启用”，相应滑块禁用，不添加伪造参数。

修改过的项目显示“保持中”，其他项目继续自然变化。保持会拦截该项的正常增减与地图重算，防止毒性或辐射刚设置就回弹。每项可点击“恢复自然”，也可“全部恢复自然变化”。恢复后温湿度从当前数值继续变化，毒性与辐射按地图状态重算；这不是恢复到修改前的存档。

**毒性和辐射滑块修改全局气候指标，不会清除污染地块、放射性地块或辐射源，也不等于解除这些地块的危险或建造限制。**没有启用相应参数的关卡不能用滑块改变该项污染。

气候修改调用游戏实际设值与阈值判定，可能触发气候条件、生态变化和奖励。完成的条件及已经发生的生态变化不会因释放保持而回退。数值随游戏正常存档保存，请按原游戏流程保存；滑块操作本身不新增撤销步骤。读档、撤销引起关卡状态替换、切换关卡或“关闭全部修改”都会停止保持，重启后不会自动恢复锁定。

## 地块拾取器

在“上帝之手”页勾选“开启地块拾取器（鼠标悬停显示名称）”。鼠标移到地图时，提示当前地块名称、坐标和海拔。取消勾选后立即隐藏并清空提示；默认关闭，不随重启保存。

拾取器可以单独开启，不需要开启地形涂抹，不改变地块或拦截原地图选择、建造。面板隐藏时也工作，指针移到修改器或原游戏界面区域时不穿透读取后方地图。涂抹提交或撤销后读取当前状态，显示名称随实际地块变化。

常见自然地形提供中文名称，建筑和其他特殊格优先使用游戏当前语言的名称；本地化尚未就绪时显示类型编号回退。提示保持在屏幕范围内。暂停、失焦或特殊交互模式时暂停显示，回到普通地图或动物需求详情模式后恢复。“关闭全部修改”会关闭拾取器。

## 上帝之手：地形涂抹

1. 进入“上帝之手”页，搜索并选择目标地形，例如草地、森林、湿地、海洋或沙漠。
2. 调整笔刷半径0—8格；0为单格，默认圆形，可改方形。
3. 在已加载且未暂停的普通关卡里点击“开启地形涂抹”。
4. 把鼠标移到地图，按住左键拖动；**松开左键后整笔提交，整笔作为一步撤销。**快速拖动会补齐经过的格子。
5. 右键取消未提交笔画并退出，或点击左上角浮动退出按钮。菜单可以展开；菜单上按下不会起笔，在菜单上松开会取消当前笔。
6. 从1.4.1开始可同时展开原游戏的具体动物需求详情。打开详情后再开启涂抹，会保留所选动物；每笔松开提交后观察原需求变化，无需关闭详情。点击详情界面不会涂抹其后方地图；暂停、迁移、教程或其他特殊操作仍不放行。右键退出涂抹不会关闭独立拾取器开关。

青色点为可涂格，红色点为跳过格，黄色点为本笔待提交格。已经是目标地形的格子不重复修改，不创建空撤销步骤。涂抹期间暂停原地图选择和建造操作，退出后恢复。

提供44种自然地形。已有建筑、地基、管道、渡槽、燃烧或放射性格以及特殊设施会跳过；不使用涂抹创建建筑或危险源。污水海洋和脏雪可作为涂抹来源。

**保留原地块高度。**海洋、河流、湖底、冰面等的视觉效果仍受关卡水面和高度规则影响；本工具不同时升降地形。暂停、教程、过场、特殊操作或失去窗口焦点时会退出涂抹并取消未提交笔画。读档或撤销在涂抹过程中替换关卡状态，也会取消旧笔画。

提交使用原游戏的地块命令、缓存刷新和自动存档，不增加或扣除叶子；原气候影响、进度和动物需求更新继续执行。因此涂抹结果会随原游戏保存；取消工具不回退已经提交的地形，需要使用撤销或存档备份。

## 一键高亮地图上所有动物

动物页点击“一键高亮地图上所有动物”，即可持续标出全部现有兽群。

- 亮色框跟随实际动物个体的位置，同物种使用一致颜色。
- 种群标签显示物种、游戏中的名字、只数和心情，可关闭名字以减少遮挡。
- 尚无可见个体模型的兽群用种群中心标记，并明确标注“种群中心”。

名单会持续刷新，包含之后出现的兽群；离开、合并、切换关卡或撤销替换状态后按当前地图重新取对象。隐藏菜单也继续显示，高亮不改变心情、活动范围、迁移或动物模型材质，也不拦截地图点击。点击同一按钮可关闭，“关闭全部修改”也会关闭。镜头外的动物需移动镜头查看。

## 指定种群的心情保持

在动物页按物种和游戏里的家族名字选择，可搜索，也可采用原游戏选中的种群。点击“只将「名字」拉满并持续保持”只影响该实际种群；支持分别保持多个家族。名单会标注单独保持，取消该群勾选即可停止。

“所有兽群一键拉满并持续保持”会开启全体保持，覆盖后续出现的兽群。只想保持指定家族时，先关闭全体保持。关闭全体保持不删除单群保持；“关闭全部修改”取消所有保持。“仅选中兽群心情拉满一次”只设置一次，没有保持时会按环境回落。

隐藏菜单不影响保持。单群保持在读档、换关卡、撤销替换关卡状态或动物离开、合并时清除，需要重新按名字选择；不套用到其他同名种群。重启后所有心情保持默认关闭。保持不伪造实际需求和动物生成条件，不复活被遣散动物，不影响迁移推荐的原始评分。

## 按名字推荐居住地和地图标记

选择具体具名兽群后，先查看物种、名字、只数、心情、领地中心和容量，再点击扫描候选。评分使用原游戏需求公式，纳入该物种实际活动范围，并按安全地块、连通地形、高度变化、同类占用和声波规则估算扩张。

扫描后，绿色小点为全部预测最高分的同分起点，带名字和数字的十字为最多5个分散代表点；菜单展开时也显示。可定位镜头和清除标记，实际迁移使用原游戏操作，不自动迁移或免除费用。

动物真实扩张还受需求优先级和随机择地影响，推荐属于估算，不能保证最终心情。地图、气候、建筑、领地、难度或范围变化后，旧预测会标橙并停止用于定位，需要重算。切换种群会清除旧推荐。

## 无限撤销默认开启

从1.4.0开始，无限撤销每次启动自动开启。原游戏允许撤销的玩家操作会累积历史，不设固定步数上限；地形涂抹每笔是一份记录。可反复使用原撤销按钮或“货币与建造”页的“撤销上一步”。

仅记录本次关卡会话。重启、读档、换关卡、进入原游戏不可撤销流程或阶段边界时清空；开启前已丢失的历史不能恢复。特殊不可撤销操作仍不强制支持撤销。

每步保存完整关卡快照，因此撤销可能同时回退动物和自然演变。每步占用内存，取消开关可释放额外历史，保留原游戏当前的最新一步。“关闭全部修改”会关闭无限撤销；下次启动仍按默认开启。货币、心情和范围等设置按钮不单独生成撤销步骤。

## 货币与建造

| 功能 | 作用 |
|---|---|
| 叶子货币 | 设置当前关卡数量0—9999999，一次设置，不持续锁定。 |
| 灌溉器范围 | 1—5倍，放大原旋转形状，填充并裁剪地图边界。 |
| 回收器范围 | 1—5倍，扩大回收建筑与陆地回收车半径，保留对象和寻路规则。 |
| 其他建筑范围 | 1—5倍，处理通用及太阳能专用半径；不扩大核污染源，不包办特殊线路长度。 |
| 任意位置建造 | 放宽地形与高度，仍拦截越界、已有建筑和危险格。 |
| 忽略建造条件 | 放宽资源、供电和气候等条件；不全解锁建筑、不免除货币成本、不创建特殊关联对象。 |

建筑倍率独立、不叠乘，主要影响后续预览和操作，不自动重算全部已建建筑的缓存关系。

## 备份、卸载与验证

本工具不替换原游戏程序集。旧插件、安装记录、原加载配置和找到的存档备份位于游戏目录 `.TerraNilTrainer`。退出游戏后可用安装工具卸载，自有文件移入可恢复目录，保留配置、日志和存档；存在其他插件时保留共享框架。恢复存档前先退出并保留当前存档副本。

源码位于 `src`，中文编译脚本位于 `scripts`，编译只生成交付包；第三方许可见“第三方许可”和 `docs/许可`。测试用的原游戏文件、资源、夹具、输入设备和玩家存档不进入交付包。

本版通过隔离人工地图、真实地块处理和原生鼠标射线验证。场景恢复、快照、可操作场景检查等部分使用夹具；未代替玩家修改当前关卡。全部地形在不同真实关卡中的视觉效果、长期生态演变和全部特殊撤销流程尚未全面验收，具体见“验证记录.md”。
