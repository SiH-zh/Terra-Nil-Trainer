# 历史版本

共保留 11 个版本（10 个首次公开归档版本及新增1.4.1）。1.2.1 从完整交付目录补打包，其余从各版冻结压缩包整理。未完成的 1.1.1 中间开发版没有发布。各版本标签对应当版源码；历史安装器和插件不做功能回填。

| 版本 | 主要变化 | 注意事项 |
|---|---|---|
| [1.4.1](https://github.com/SiH-zh/Terra-Nil-Trainer/releases/tag/v1.4.1) | 动物需求详情内涂抹；独立地块名称拾取开关。 | 可见提示外观及真实需求详情更新待实际游戏确认。 |
| [1.0.0](https://github.com/SiH-zh/Terra-Nil-Trainer/releases/tag/v1.0.0) | 初版：叶子货币、灌溉与回收范围、建筑范围、任意位置建造及忽略建造条件。 | “检查与预览”存在响应问题；默认 F8，可能与其他软件冲突。 |
| [1.0.1](https://github.com/SiH-zh/Terra-Nil-Trainer/releases/tag/v1.0.1) | 修复安装工具“检查与预览”的响应与反馈。 | 默认 F8，可能与其他软件冲突；不含后续动物及输入修复。 |
| [1.1.0](https://github.com/SiH-zh/Terra-Nil-Trainer/releases/tag/v1.1.0) | 新增动物心情、动物活动范围与迁移候选推荐。 | 默认 F8；早期加载入口在当前环境可能不能正常运行面板。 |
| [1.2.0](https://github.com/SiH-zh/Terra-Nil-Trainer/releases/tag/v1.2.0) | 默认快捷键改为 F6，新增自定义单键及组合键。 | 早期加载入口在当前环境可能导致面板和快捷键无响应。 |
| [1.2.1](https://github.com/SiH-zh/Terra-Nil-Trainer/releases/tag/v1.2.1) | 修复加载入口生命周期，恢复游戏内面板与按键响应。 | 菜单展开时可能拦截地图输入，需隐藏菜单才可正常预览和建造。 |
| [1.2.2](https://github.com/SiH-zh/Terra-Nil-Trainer/releases/tag/v1.2.2) | 修复面板对地图鼠标输入的拦截，面板外可正常预览及建造。 | 早期动物推荐准确度有限，单次拉满心情会随环境回落。 |
| [1.3.0](https://github.com/SiH-zh/Terra-Nil-Trainer/releases/tag/v1.3.0) | 按真实兽群名字选择动物、推荐最高分候选点并在地图标记；新增无限撤销开关。 | 全体一键拉满为单次操作，心情会随环境回落；无限撤销默认关闭。 |
| [1.3.1](https://github.com/SiH-zh/Terra-Nil-Trainer/releases/tag/v1.3.1) | 全体动物一键拉满后自动持续保持，修复心情自动回落。 | 尚无指定兽群持续保持及面板缩放；无限撤销默认关闭。 |
| [1.3.2](https://github.com/SiH-zh/Terra-Nil-Trainer/releases/tag/v1.3.2) | 新增面板边框与四角拖动缩放，支持指定兽群持续满心情。 | 尚无物种独立范围、地形笔刷与全图动物高亮；无限撤销默认关闭。 |
| [1.4.0](https://github.com/SiH-zh/Terra-Nil-Trainer/releases/tag/v1.4.0) | 新增按物种独立扩大活动范围、上帝之手地形涂抹、一键高亮全部动物；无限撤销每次启动默认开启。 | 迁移推荐是估算；水体地形视觉受高度影响；尚未全面验证所有真实关卡、生态演变及特殊撤销流程。 |

1.0.0—1.3.2以历史预发布版归档，1.4.0为首次正式公开版本，1.4.1是当前推荐版本。首次归档的旧包去除本机记录和展示截图，保留原运行二进制；新版本按源码重新编译，并附公开图文教程。
