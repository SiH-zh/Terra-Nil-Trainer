# 第三方组件来源

本安装包附带的加载框架来自 [BepInEx（模组加载框架）5.4.23.5 官方发布包](https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.5)。发布包文件名为 `BepInEx_win_x64_5.4.23.5.zip`，已与官方发布元数据中的 SHA-256（文件校验算法）核对：

```
82F9878551030F54657792C0740D9D51A09500EEAE1FBA21106B0C441E6732C4
```

库文件保持官方发布包原样，没有修改。对应源码仓库如下：

- [BepInEx（模组加载框架）源码与版本标签](https://github.com/BepInEx/BepInEx/tree/v5.4.23.5)，许可证文件 `BepInEx-LICENSE.txt`。
- [HarmonyX（运行时补丁库）2.9.0 源码](https://github.com/BepInEx/HarmonyX/tree/v2.9.0)，许可证文件 `HarmonyX-LICENSE.txt`。
- [MonoMod（运行时修改库）22.1.29.1 源码](https://github.com/MonoMod/MonoMod/tree/v22.01.29.01)，许可证文件 `MonoMod-LICENSE.txt`。
- [Mono.Cecil（程序集处理库）0.10.4 源码](https://github.com/jbevain/cecil/tree/0.10.4)，许可证文件 `Mono.Cecil-LICENSE.txt`。
- [UnityDoorstop（加载入口）源码](https://github.com/NeighTools/UnityDoorstop/tree/v4.5.0)，许可证文件 `UnityDoorstop-LICENSE.txt`。

“源码”目录为本修改器与安装工具的完整源代码。安装包不包含游戏程序集和游戏资源。第三方许可证保留官方英文原文；其用途是说明组件使用、修改、分发时的授权条件。本中文说明不替代许可证原文。
