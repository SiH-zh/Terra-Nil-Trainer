# 1.2.2 面板与建造交互修复验证

验证日期：2026年10月13日，北京时间。

## 原因与修复

实际安装的1.2.0日志显示插件完成加载，但用户看不到面板。隔离副本采用原加载入口时，运行到第120帧，插件更新和界面绘制次数均为0；加载框架管理对象及插件原生实例已失效。先前只在加载期间手动调用按键处理函数，未覆盖实际生命周期，不能证明界面能用。

将加载入口切换到 `UnityEngine.CoreModule.dll / MonoBehaviour / .cctor` 后，正常帧循环能调用插件，真实窗口能绘制中文面板。这也是[加载框架官方对较新游戏引擎的排错方法](https://docs.bepinex.dev/articles/user_guide/troubleshooting.html#change-the-entry-point)。

安装工具已加入入口修复，保留其他配置和注释，修复前按原始字节备份加载配置。相同插件版本也会检查并修复入口。插件加入更新、绘制和快捷键触发日志；隐藏后可点击左上角“打开修改器”。没有绘制的面板不会拦截建造操作。

## 本轮结果

- 安装、算法、备份、升级、卸载和快捷键配置：67项通过，包括新增的首次安装入口、旧入口修复、原始字节备份、重复操作不改写和同版本修复检查。
- 安装工具真实按钮事件与后台反馈：9项通过，另有离屏截图。
- 隔离游戏真实图形窗口：实际更新174次、界面回调346次；启动面板可见、组合键隐藏后按钮可见、再次组合键恢复面板。测试配置为控制键加F6；单按F6不误触发。截图已经检查。
- 本轮图形测试通过虚拟键盘进入正常游戏输入与帧循环，没有向用户游戏或系统发送按键，没有直接调用插件更新方法。
- 现有功能运行时自检通过；人工地图动物测试19项通过；按键配置、录制、持久保存与恢复15项通过。这些逻辑自检使用隔离副本的人工场景，启动日志有测试环境产生的原游戏初始化空引用，不能当作完整关卡验收。
- 加载修复1.2.1曾安装到实际目录，插件文件与交付载荷校验值一致；当前快捷键保留为F6。原游戏代码和快捷键配置校验值保持一致，升级备份包含原插件、安装清单和当前存档，另有原加载配置备份。

## 范围与限制

图形测试使用完整游戏副本、独立测试存档路径，跳过游戏平台初始化，不进入玩家关卡。测试补丁、测试程序集、游戏原程序集和玩家存档均未包含在载荷中。

本轮验证了真实面板和按键帧循环，尚未完成玩家关卡中货币刷新、建造效果、回收动画、动物实际迁移、镜头定位和地图标记的全面交互验收。动物位置推荐仍属于当前地图估算，不保证未来环境下的全局最优。

交付插件、安装工具和中文编译脚本均已成功编译；编译脚本保存为带签名字节的统一字符编码，通过系统脚本环境5.1检查。构建脚本不会自行安装到游戏目录。
