# 1.4.0 验证记录

使用当前游戏平台构建22566272、游戏1.2.12和原游戏程序集进行编译与隔离验证。原游戏程序集没有改写或分发。

## 检查结果

- 61项动物运行时检查通过：保留心情保持、具名选择、评分、危险格、容量、领地扩张与对象生命周期检查；新增物种独立倍率、覆盖通用而不叠乘、明确1倍覆盖、恢复继承、推荐签名变化和清空设置；高亮取全部兽群、刷新、关闭及重置。
- 32项地形涂抹检查通过：44种自然目标、单格、圆形和方形、地图边界、连续路径、建筑及管线占用、危险格、污水来源、去重、原高度及其他字段保留、原生地块处理、真实类型变化、整笔撤销、菜单拦截、取消和状态变化。
- 15项无限撤销检查通过，含新模块默认开启、连续三步、1200步无固定上限、新分支、关闭释放、边界、外部状态替换和非玩家命令过滤。
- 15项快捷键检查通过；15项面板尺寸策略检查通过。
- 22项图形界面与建造交互检查通过：保留面板内外与缩放检查；正常启动默认开启撤销；从两群真实图形组件取得6个个体位置；原生鼠标射线正确选格；虚拟鼠标在实际帧更新中起笔、拖动、松开提交两格、整笔撤销与右键退出。
- 67项范围算法、安装、升级、备份、卸载、配置和文件边界检查通过；9项安装工具按钮事件检查通过。
- 已查看图形预览：物种设置、动物高亮、地形工具、笔刷待提交点、实际变为草地的两个示例格子以及原功能面板。移除了隔离启动画面的遮挡，工具文字和标记可读。

## 验证边界

所有功能测试使用工作目录下的隔离副本和人工地图；虚拟键盘、虚拟鼠标及合成界面事件只进入该副本，不向玩家游戏发送输入。未代替玩家涂抹、迁移或改心情。

地形测试调用真实的地块变更、类型缓存和动物领地脏标记逻辑。无图形测试用空气候配置夹具；图形测试保留原生地形命令构造函数和鼠标射线，命令场景处理、快照、场景恢复、可操作场景检查及方块显示使用夹具，避免触发玩家存档或依赖不完整场景。它证明选格、笔画、目标地形与撤销链可以配合，不证明44种地形在所有真实关卡中的原生素材、水面、气候与进度效果。

高亮预览使用两群示例名字、6个禁用自主移动的原游戏个体组件和球形示例模型；实际位置从组件的变换读取。不是玩家当前地图，也不是动物真实外观。实际可见模型使用亮色框，缺少模型时明确显示种群中心。

连续撤销的命令与场景恢复使用夹具，不能据此承诺全部特殊流程恢复；真实完整快照每步占用内存。游戏本来不可撤销的边界仍清空历史。

推荐评分继续为按原公式与扩张限制得到的估算，不完全复刻需求优先级和随机择地。水体高度、长期生态演变、所有物种与地形组合、全部特殊建筑和真实关卡多步恢复尚未全面验收。
